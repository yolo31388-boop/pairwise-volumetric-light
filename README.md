# pairwise-volumetric-light

林间光束在相机移动时整片闪烁，体积光按屏幕空间步进，步长随深度线性增长，近处过密远处断层；阴影贴图采样没做蓝噪抖动，光束边缘出现条带；半分辨率渲染上采样用双线性，树枝缝隙漏出方形光斑；深度遮挡只比较中心采样，细树叶挡不住光柱；时域累积没有运动矢量，相机横移时光束拖影；雾密度按高度指数衰减但没按光源方向积分，逆光时整片发白；多光源各自加一次散射，交叠区域能量爆掉；HDR 亮度直接进 8bit 缓冲，太阳附近出现硬切；性能档减少步数却没重新归一化透射率，光束变暗；光束与透明粒子混合顺序错误，雨滴把光柱整条遮黑。render/volumetric_light.py 是核心，tests/test_volumetric_light.py 15个红。要修的是：步长按视深自适应；采样加蓝噪抖动；上采样按深度保边；遮挡多点采样；重投影带运动矢量；密度按光路积分；多光源能量归一；HDR 全链路；降档重算透射率；光柱与粒子分层合成。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
